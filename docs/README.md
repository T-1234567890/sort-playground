# Sort Playground Docs

Sort Playground is a static React/Vite app for exploring sorting algorithms through animation, source code, exports, and contribution-friendly folders.

## Docs Index

- [Architecture](./architecture.md)
- [Adding Algorithms](./adding-algorithms.md)
- [Export Features](./exports.md)
- [Contributor Guide](./contributors.md)

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

The app builds to `dist/` and can be deployed to static hosts such as GitHub Pages or Cloudflare Pages.
